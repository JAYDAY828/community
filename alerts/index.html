홈 화면에 추가해 주세요

iPhone과 iPad는 홈 화면에 추가한 앱에서만 알림을 받을 수 있습니다.

  1. Safari에서 이 페이지를 엽니다.
  2. 아래쪽 공유 버튼을 누릅니다.
  3. 홈 화면에 추가를 누릅니다.
  4. 홈 화면에 생긴 Alerts 아이콘으로 다시 엽니다.

이 브라우저에서는 알림을 받을 수 없습니다

iPhone과 iPad는 iOS 16.4 이상이 필요합니다. 메신저 안에서 열린 화면이라면 Safari로 열어 주세요.

알림이 꺼져 있습니다

기기의 설정 > 알림 > Alerts에서 알림을 허용한 뒤 이 화면을 다시 열어 주세요.

알림이 꺼져 있습니다

ENABLE을 누르고 알림을 허용하면 이 기기의 연결 코드가 만들어집니다.

이 기기는 알림을 받을 수 있습니다

연결 코드

이 코드를 PC로 보내 프로그램의 Push 설정에 붙여 넣으면 연결됩니다.

코드는 비밀번호처럼 다뤄 주세요

이 코드를 가진 사람은 이 기기로 알림을 보낼 수 있습니다. 다른 사람에게 보였다면 RESET으로 새 코드를 만드세요. 이전 코드는 그 즉시 쓸 수 없게 됩니다.

연결 코드를 다시 만들어야 합니다

이 기기에 저장해 둔 정보가 지워져 예전 코드를 다시 보여 드릴 수 없습니다. ENABLE을 누르면 새 코드가 만들어지고, 이전 코드는 쓸 수 없게 됩니다.

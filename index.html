Getting Started

바이낸스 오더툴킷 사용을 위한 API 키 발급 및 등록 방법을 안내합니다.

바이낸스 공식 API 변경사항

최신 API 사양과 변경 일정은 바이낸스 공식 개발자 문서에서 직접 확인할 수 있습니다.

1) 발급 절차

  1. 바이낸스 로그인 후 우측 상단 [Account] → [API Management] 메뉴로 이동합니다.
  2. [Create API] 클릭 후 System generated 방식을 선택합니다.
  3. Label(이름)을 입력합니다. (예: futures-toolkit)
  4. 이메일 및 OTP 인증(Security Verification)을 완료하여 키를 생성합니다.

2) API 권한 설정 (Restrictions)

반드시 체크 (허용)

  • Enable Reading
  • Enable Futures

체크 해제 (금지)

  • Enable Spot & Margin Trading
  • Enable Withdrawals (출금)

본 툴킷은 Enable Futures(선물 거래) 권한만 있으면 모든 기능이 정상 작동합니다.
운영자는 개인 자산(현물 거래, 출금 등)에 대한 권한을 전혀 요구하지 않으므로 안심하셔도 됩니다.

권한이 안 보이거나 주문이 실패할 때

  • ● 신규 계정은 Futures 거래 동의를 먼저 완료해야 API 설정 화면에 Enable Futures 항목이 표시됩니다.
  • ● TradFi 상품은 일반 선물 거래 동의와 별도로 TradFi 거래 동의가 필요합니다.
  • ● Order Toolkit 제목 표시줄에 ERROR가 한 번이라도 표시됐다면, Ctrl + Shift + Esc → 작업 관리자에서 Order Toolkit을 강제 종료한 뒤 다시 실행하세요.

3) IP 제한 설정 (보안 필수)

  1. API 설정 화면 하단의 IP Access Restrictions 항목을 확인합니다.
  2. Restrict access to trusted IPs only(권장) 옵션을 선택합니다.
  3. 네이버 검색창에 내 IP를 검색하여 본인의 IP 주소를 확인합니다.
  4. 확인된 IP 주소를 입력란에 붙여넣고 Confirm을 누른 뒤, 상단의 Save 버튼을 눌러 저장합니다.
허용된 IP 이외의 환경(다른 PC, 외부 네트워크 등)에서는 API가 동작하지 않아 안전합니다.

4) Order Toolkit에 입력

  1. 발급 완료 화면에 표시된 API Key와 Secret Key를 복사합니다.
  2. Order Toolkit 프로그램을 실행합니다.
  3. 상단 메뉴의 [API] 버튼을 클릭하여 복사한 키를 입력하고 저장합니다.

주의사항

  • ● Secret Key는 생성 직후 1회만 표시되며, 페이지를 벗어나면 다시 확인할 수 없습니다.
  • ● Secret Key를 분실한 경우 API를 삭제하고 새로 생성해야 합니다.

Automated Trading Bot은 Crypto Detector에서 포착된 급등/급락 신호를 로컬 소켓(Local Socket)을 통해 Order Toolkit으로 즉시 전송합니다. 툴킷은 수신된 신호를 받아 3초 타임아웃(Timeout) 규칙을 적용하여 바이낸스 서버로 주문을 전송하며, 체결 즉시 안전 장치(Auto SL)를 가동합니다.

2) 설정 및 준비

STEP 1 Order Toolkit 설정

  • Enable Bot Connection: 봇 연동 활성화
  • Auto SL (%): 자동 스탑로스 설정
  • Auto TP (%): 자동 익절 설정
  • Auto Qty (USDT): 진입 금액 설정
  • Entry Delay: 진입 지연 시간
  • Max Symbols: 동시 진입 제한

STEP 2 Crypto Detector 설정

  • 상단 BOT 버튼 클릭 → 활성화(Green)
  • 감지 시 자동으로 신호 송신 시작

3) 핵심 매매 로직 및 안전 장치

주문 추적 (Unique Client ID)

모든 봇 주문은 BOT_E_... 형식의 고유 ID를 부여받습니다. 이를 통해 툴킷은 수동 주문과 봇 주문을 완벽하게 구분하며 최적화된 로직을 적용합니다.

3초 타임아웃 (3s Timeout)

진입 주문 후 3초 이내에 체결되지 않으면 주문은 즉시 취소됩니다. 고점에 물리는 것을 방지하는 강력한 속도 기반 리스크 관리 기능입니다.

연결 안정성 (Socket Retry)

연결이 끊어질 경우 최대 3회까지 자동 재접속을 시도합니다. 일시적인 네트워크 불안정 시에도 신호 누락을 최소화하여 안정성을 보장합니다.

4) 실전 운용 팁

  • PORT CHECK

    포트 12345는 윈도우 방화벽에서 기본 허용되지만, 타사 백신 사용 시 예외 처리가 필요할 수 있습니다.

  • MANUAL OVERRIDE

    봇이 작동 중일 때 사람이 개입하여 '청산' 버튼을 누르면, 봇 로직보다 사용자의 수동 명령이 최우선으로 처리됩니다.

Real-time Order Book

웹보다 빠른 실시간 호가창 및 매물대 분석 뷰어입니다.

1) 소개 및 주요 특징

바이낸스 웹사이트의 호가창(Snapshot 방식)은 갱신 주기가 느려 스캘핑에 불리합니다. 본 뷰어는 Socket 기반 리얼타임 호가창으로, 결정적인 순간의 매수/매도 벽과 체결 강도를 실시간으로 포착합니다.

실시간 USDT 환산

모든 호가 물량을 코인 개수가 아닌 USDT(금액) 가치로 자동 환산하여 표시합니다. 허수 주문과 실제 매물대를 직관적으로 파악할 수 있습니다.

보조지표

최근 3초 누적 체결대금과 FOLLOW / ABSORB 신호를 함께 표시하여, 체결대금이 실제로 가격을 밀어 진행시키는지, 바로 흡수되어 막히는지를 빠르게 읽을 수 있습니다.

강력한 모아보기

틱(Tick) 단위뿐만 아니라 10, 100, 1000 단위의 Aggregation(모아보기)을 지원하여 시장의 깊이(Depth)를 다각도로 분석합니다.

툴킷 연동

호가창의 특정 가격을 클릭하면 Order Toolkit의 가격 입력창에 즉시 반영되어 빠른 지정가 주문이 가능합니다.

2) 메인 UI 및 컨트롤

  • GLOBAL / SYMBOL 모아보기(Aggregation) 설정을 모든 종목에 공통 적용할지(GLOBAL), 각 종목별로 개별 저장할지(SYMBOL) 선택합니다.

실시간 체결 내역 필터링 및 청산(Force Order) 감지 뷰어입니다.

1) 소개 및 주요 특징

바이낸스 웹에서 제공하는 체결내역은 단순 스냅샷으로, 시장의 속도와 중요 체결을 놓치기 쉽습니다. 본 툴은 거래대금 필터를 통해 '의미 있는 체결'만 선별하여 보여주며, 청산(Liquidation) 이벤트를 실시간으로 포착합니다.

거래대금 필터링

설정된 금액(USD) 미만의 자잘한 체결은 걸러내고, 고래들의 대량 체결만 시각적으로 강조하여 흐름을 파악합니다.

청산(Liquidation) 감지

단기 추세의 변곡점이 될 수 있는 강제 청산(Force Order) 발생 시, 알림음과 팝업으로 즉시 알려줍니다.

  • Last Price: 중앙에 현재 체결가와 등락 방향을 크게 표시합니다.
  • Indicators: 3초 매수/매도 총 체결, D1 / D3 / BIG / FLOW, 1M LIQ와 체결 강도 이퀄라이저를 표시합니다.

최근 3초 동안 매수/매도 체결대금이 각각 얼마나 실렸는지 보여줍니다. 순델타만으로는 가려지는 실제 매수·매도 합산 규모를 빠르게 확인하기 위한 칸입니다.

D1 / D3 Delta
+ BUY - SELL

순델타를 1초(D1)와 3초(D3) 기준으로 분리합니다. 양수는 매수 우세, 음수는 매도 우세이며, D1은 순간 반응, D3는 좀 더 안정적인 흐름을 읽는 데 유용합니다.

BIG Large-Trade %
0% – 100%

최근 3초 구간에서 큰 체결이 차지하는 비중입니다. 왼쪽 기호는 큰 체결로 분류된 체결금액의 우세 방향을 뜻하며, 30 / 60 / 85% 단계부터 색상이 강해집니다.

FLOW 상태 해석

강한 델타 우세가 있을 때, 가격이 어떻게 반응하는지를 세 가지 상태로 구분합니다.

FOLLOW

때리는 쪽이 이기고 있음

델타와 가격이 같은 방향으로 움직이는 상태입니다. 시장가 공격이 유동성을 뚫고 가격을 밀어내고 있습니다.

NEUTRAL

아직 둘 다 애매함

델타 방향성은 있지만 가격 반응이 뚜렷하지 않은 상태입니다. 아직 방향이 확정되지 않았습니다.

ABSORB

받아내는 쪽이 버티거나 이기고 있음

한쪽 델타가 강한데 가격이 그 방향으로 못 가거나 거의 움직이지 못합니다. 대기 물량이 두껍거나 반대편이 계속 받아주고 있다는 뜻입니다.

ABSORB가 나타나면 체결량은 강한데 가격 반응이 약하다는 뜻이므로, 추세 지속보다 정체·흡수·반전 가능성을 함께 의심해야 합니다.

함께 읽는 법

D3 + FLOW

먼저 델타로 어느 쪽이 우세한지 보고, FLOW로 그 우세가 실제 가격 진행인지 흡수인지 구분합니다.

3S GROSS + D1 / D3

3초 매수·매도 합산 규모가 큰데 델타 차이가 작으면 양방향 공방이 큰 상태이고, 합산 규모와 델타가 함께 커지면 방향 에너지가 응축된 구간입니다.

D1 / D3 + I ~ IIIII

EQ는 총 5단계 지표입니다. III는 따라붙는 진입 근거가 생긴 구간, IIII는 힘이 유지되거나 더 붙는 구간, IIIII는 가장 강한 폭발 구간으로 읽으면 됩니다.

1M LIQ + KEY LEVEL

의미있는 캔들에서 굵직한 청산 금액이 발생한 경우, 해당 위치가 단기 변곡점이 될 가능성이 매우 높음

3) 청산(Liquidation) 감지

Force Order 이벤트를 별도의 팝업창에 기록합니다. 다른 툴킷으로 종목 변경 시, 해당 종목의 청산 내역만 남기고 이전 기록은 자동 삭제됩니다.

표시 데이터

  • TIME : 발생 시각
  • SIDE : 청산 방향 (Long / Short)
  • PRICE : 청산 가격
  • QTY / VALUE : 청산 물량 및 금액 (K/M/B 단위 축약)
  • * 1M / 3S 통계를 통해 1분/3초간 누적된 청산 규모를 보여줍니다.

알림 옵션 (Alerts)

  • AUTO POPUP (3s) 청산 발생 시 자동 팝업 후 3초 뒤 숨김
  • ALERT SOUND 청산 발생 시 경고음 재생
  • MIN SIZE 설정된 금액 이상의 청산만 알림
Tip: 오토 팝업을 끈 상태에서 창이 닫혀있더라도, 조건에 맞는 청산이 발생하면 메인 UI의 LIQ 버튼에 NEW 배지가 깜빡여 알려줍니다.

4) 설정 및 마켓 전환

설정 (SET)

  • Highlight Large Trades 설정한 금액(USD) 이상의 체결 건을 굵은 폰트로 강조하여 보여줍니다. (필터링 핵심)
  • Rows 테이블에 표시할 최대 행 개수를 조절합니다. (10 ~ 100)

마켓 전환 (PERP/Spot)

선물(Futures) 데이터뿐만 아니라 현물(Spot) 체결내역으로 전환하여 볼 수 있습니다.

* 단, 해당 심볼이 현물 마켓에 상장되어 있지 않은 경우 버튼이 비활성화됩니다.

5) 문제 해결

  • 데이터가 멈추거나 지연됩니다. 네트워크 상태를 확인하세요. 바이낸스 소켓 연결이 끊긴 경우 SET → Apply를 눌러 재연결을 시도하세요.
  • 현물(Spot) 전환이 안 됩니다. 해당 코인이 바이낸스 현물 마켓(USDT)에 상장되어 있는지 확인해주세요. 미지원 시 PERP 모드로 고정됩니다.
  • 청산 알림음이 안 들립니다. 프로그램 폴더 내 SFX 폴더에 liq.wav 파일이 존재하는지, 윈도우 볼륨 믹서 설정을 확인하세요.
